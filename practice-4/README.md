# Практическая работа №4: Потоки и процессы

**Вариант B (основной).**

Сумма 100 000 чисел считается последовательно, четырьмя потоками и четырьмя процессами. Каждый режим запускается три раза, выводится медиана. Это соответствует варианту B; сетевой бенчмарк можно добавить аналогично через ThreadPoolExecutor.

## Запуск

```bash
python3 solution.py
```
