# Практические работы по проектированию операционных систем

Репозиторий содержит решения практических работ №1–8 по дисциплине «Операционные системы». Все работы выполнены в варианте B и сопровождаются сохранёнными результатами, тестами и графиками.

## Структура каждой работы

В каждой папке находятся исходные программы, README с подробным отчётом и каталог `results/`. В `results/` сохранены результаты запусков, таблицы, логи и графики, чтобы преподаватель мог проверить итог без повторного запуска всех команд.

## Среда выполнения

Практики рассчитаны на Linux или Ubuntu/WSL2, Python 3.10+ и Bash. Для работ с `/proc`, `fork`, FIFO, Unix-сокетами, сигналами и `fcntl` требуется Linux-среда. Дополнительные Python-пакеты не используются.

## Что проверяется

- работа с пользователями, группами и правами доступа;
- Bash-обработка журналов и взаимодействие с системными вызовами;
- создание процессов, `fork`, `exec`, zombie/orphan и Copy-on-Write;
- сравнение потоков и процессов;
- алгоритмы FCFS, SJF, SRTF, Priority, Round Robin и MLFQ;
- семафоры, мьютексы, производители и потребители;
- pipe, FIFO, сигналы, конвейеры, сокеты и общая память;
- воспроизведение deadlock, исправление блокировок, детектор циклов и Banker.
