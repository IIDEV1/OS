# Практическая работа №12: Файловая система Linux

**Вариант B (основной).**

`backup.sh` делает инкрементальную копию с журналом и сохранением прав через rsync. `dedup.py` ищет дубликаты по SHA-256; замена на жёсткие ссылки выполняется после проверки списка.

## Запуск

```bash
python3 solution.py
```
