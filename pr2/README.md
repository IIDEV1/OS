\## Bash и системные вызовы — вариант B



\### 1. Скрипт report.sh



Скрипт принимает каталог с журналами и уровень сообщений ERROR или WARN.



Формат запуска:



./report.sh <каталог> <ERROR|WARN> \[--top N]



Пример:



./report.sh data ERROR --top 3



Результат:



db 637

net 600

disk 321



Скрипт сортирует модули по убыванию количества сообщений.



Также реализована проверка аргументов:

\- отсутствие аргументов;

\- неверный уровень;

\- несуществующий каталог;

\- неверное значение N.



При ошибке выводится справка в stderr и программа завершается с кодом 1.



\### 2. Программа hello.py



Программа hello.py получает путь к файлу, читает его и выводит размер файла в байтах.



Команда:



python3 hello.py data/01.log



Результат:



19076



Проверка через stat также показала:



19076 байт



\### 3. Анализ системных вызовов Python



Для получения трассировки использовалась команда:



strace -f -o trace.txt python3 hello.py data/01.log



Для получения статистики:



strace -f -c -o python\_stats.txt python3 hello.py data/01.log



Общее количество системных вызовов Python:



409



Из них непосредственно с файлом data/01.log связаны 4 вызова:



1\. openat() — открытие файла;

2\. read() — чтение содержимого файла;

3\. read() — проверка конца файла, возвращает 0;

4\. close() — закрытие файла.



Таким образом, непосредственно вызовов read() было 2, а всего системных вызовов, связанных с открытием, чтением и закрытием исследуемого файла, — 4.



Остальные системные вызовы являются в основном накладными расходами запуска интерпретатора Python. Перед выполнением программы Python должен загрузить интерпретатор и динамические библиотеки, проверить пути и модули, выделить память и выполнить другие служебные операции.



\### 4. Сравнение Python и cat



Для команды cat использовались:



strace -f -o trace\_cat.txt cat data/01.log



strace -f -c -o cat\_stats.txt cat data/01.log



Получены следующие результаты:



| Программа | Системных вызовов |

|-----------|-------------------|

| python3 hello.py | 409 |

| cat | 144 |



Python выполнил значительно больше системных вызовов, чем cat.



Это связано с тем, что cat является готовой нативной программой и выполняет сравнительно небольшое количество действий для открытия, чтения и вывода файла.



Python перед выполнением hello.py сначала запускает интерпретатор, загружает необходимые библиотеки и выполняет множество служебных операций. Поэтому у Python больше накладных системных вызовов.



\### Вывод



В ходе работы был написан Bash-скрипт report.sh для анализа журналов и Python-программа hello.py для чтения файла.



С помощью strace было установлено, что python3 hello.py выполнил 409 системных вызовов, тогда как cat выполнил 144 системных вызова.



Непосредственная работа Python с исследуемым файлом потребовала 4 системных вызова: openat, двух read и close. Большая часть остальных вызовов связана с запуском и работой интерпретатора Python.



Следовательно, выполнение простой операции через интерпретируемый язык имеет дополнительные накладные расходы по сравнению с небольшой нативной программой.
