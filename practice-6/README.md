# Практическая работа № 6 — Классификация текстов

Автор: ISLAM (IIDEV1).

Работа выполнена по приложенному заданию дисциплины «Машинное обучение»: уровни A, B и C.

## Содержание

- `practice-6.ipynb` — выполненный notebook с сохранёнными выводами и графиками.
- `preprocessing.py` — очистка, токенизация, русские стоп-слова с сохранением отрицаний, Snowball-стемминг.
- `data/reviews.csv` — 3000 реальных русскоязычных отзывов, по 1000 на класс.
- `data/provenance.json` — источник, параметры выборки и SHA-256 данных.
- `data/LICENSE` — исходная лицензия Apache-2.0 на корпус.
- `prepare_data.py` — воспроизведение отбора из исходного TSV с проверкой контрольных сумм.
- `results/` — таблицы метрик, пять ошибок и графики.
- `requirements.txt` — версии библиотек, использованные при выполнении.

## Запуск

В терминале перейдите в папку `practice-6`, создайте окружение Python 3.12:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Откройте `practice-6.ipynb` в VS Code с расширением Jupyter, выберите созданное окружение и выполните **Restart Kernel → Run All**. Интернет после установки библиотек не нужен: данные включены, стеммер не требует загрузки словарей NLTK.

Для выполнения без интерфейса:

```powershell
python run_notebook.py
```

Для повторного формирования выборки скачайте исходный CSV по ссылке в `data/provenance.json` и передайте путь команде `python prepare_data.py <путь-к-исходному-файлу>`. Несмотря на расширение CSV, исходный файл разделён табуляцией. Готовая учебная выборка уже включена в репозиторий.

## Эксперимент

Одинаковое стратифицированное разбиение 80/20, seed=42. Все обучаемые преобразования находятся внутри Pipeline и обучаются только на train. Сравниваются BoW + MultinomialNB, TF-IDF + MultinomialNB и TF-IDF + LogisticRegression. Метрики — accuracy и macro-F1; приведены отчёты по классам и матрицы ошибок. Дубли очищенных текстов исключены до разбиения.

## Источник данных

[RuReviews](https://github.com/sismetanin/rureviews), Sergey Smetanin и Michail Komarov. *Sentiment Analysis of Product Reviews in Russian using Convolutional Neural Networks*, IEEE CBI, 2019, pp. 482–486, DOI: 10.1109/CBI.2019.00062.

Учебный CSV — самостоятельно отобранный подкорпус готового открытого набора, а не самостоятельно написанные отзывы. Авторы набора использовали пользовательские оценки для автоматической разметки. Сохраняются три исходных класса: negative, neutral, positive. Возможен шум меток. Из-за балансировки и ограниченной тематики результаты не описывают реальный поток отзывов магазина.

## Результат проверенного запуска

2400 отзывов в train, 600 в test, 5640 признаков.

| Модель | Accuracy | Macro-F1 |
|---|---:|---:|
| BoW + MultinomialNB | 0.6817 | 0.6799 |
| TF-IDF + MultinomialNB | 0.6850 | 0.6816 |
| TF-IDF + LogisticRegression | 0.7050 | 0.7047 |

Все ячейки выполнены без ошибок, выводы сохранены. Опечатка исходной метки `neautral` исправлена на `neutral`. Полный разбор пяти ошибок приведён в notebook и `results/error_analysis.md`. Сравнение относится к одному фиксированному разбиению; статистическая значимость различий не установлена.
